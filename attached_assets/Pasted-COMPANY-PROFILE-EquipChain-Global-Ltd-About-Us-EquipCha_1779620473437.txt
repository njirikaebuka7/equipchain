COMPANY PROFILE
EquipChain Global Ltd

About Us
EquipChain Global Ltd. is an indigenous Nigerian procurement, supply chain, logistics, and industrial support company providing reliable solutions to the oil & gas, energy, manufacturing, infrastructure, mining, water, and process-driven sectors.
We connect industries to trusted equipment, instrumentation, automation products, industrial materials, and technical supplies through a responsive end-to-end procurement and logistics support model. With strong local market understanding, global supplier networks, technical knowledge, and practical industry experience, we help clients simplify sourcing, reduce operational delays, control costs, and maintain business continuity.
Driven by integrity, responsiveness, safety, professionalism, and execution excellence, EquipChain Global Ltd. is committed to building long-term partnerships and delivering dependable support solutions that keep critical operations moving.

# 9. SEO Requirements
This website must be highly SEO-oriented.

## Technical SEO
Implement:
- Proper semantic HTML: `header`, `main`, `section`, `article`, `footer`, `nav`
- Every page must have a unique meta title
- Every page must have a unique meta description
- Add Open Graph tags for social sharing
- Add Twitter card meta tags
- Use canonical URLs
- Add structured data using JSON-LD
- Generate `sitemap.xml`
- Generate `robots.txt`
- Use clean, readable URLs
- Optimize page speed
- Lazy-load images
- Use descriptive image alt text
- Use proper heading hierarchy: one H1 per page, then H2/H3
- Use internal linking between services, industries, capabilities, contact, request quote, and insights pages
- Use breadcrumbs where suitable
- Use optimized page titles targeting oil & gas procurement and industrial supply services
- Avoid duplicate page titles and duplicate meta descriptions
- Use SEO-friendly slugs for blog posts
- Ensure all public pages are indexable except admin pages

# 21. Request a Quote Page

-	Do not use one long form.

The quote form must feel modern, smooth, and premium.

## Multi-Step Form Flow
### Step 1: Basic Information

- Full Name
- Company Name
- Email Address
- Phone Number

### Step 2: Service Needed
Use selectable cards:
- Procurement & Supply
- Supply Chain & Logistics
- Oil & Gas Support
- Project Support
- Industrial Services
- Other (if other is selected, a new input field should show for the user to enter the other service needed)

### Step 3: Request Details
- Product / service needed
- Quantity, if applicable
- Specification / description
- Required delivery timeline
- Preferred sourcing type: local / international / no preference

Please note that these request details should be based on the service type selected here (### Step 2: Service Needed)

### Step 4: Upload / Additional Info
- Upload RFQ, BOQ, specification sheet, or supporting document
- Additional message

### Step 5: Review & Submit
Show summary before submission.

After submission:
- Show success message
- Send notification to admin if configured
- Save request to database
- Optional email confirmation to requester
